# Exact check: is random eviction needed?

An exact-arithmetic bench for **anytime-uniform reservoir sampling**: sample `k` items
uniformly from a stream of unknown length so that the reservoir after *every* prefix `i`
is a uniformly random `k`-subset of `[i]`, not just the reservoir at the end.

Two instruments run side by side in one pipeline on the same candidates and the same
cells, so nothing in the comparison is contaminated by a difference in the measurement
path.

| | Baseline | Our method |
|---|---|---|
| what | Monte-Carlo uniformity test: run `T` streams, count how often each item ends in the reservoir, report the max deviation from `k/n` | exact-rational prefix DP over sampler states + the eviction step solved as a transportation problem |
| arithmetic | float, sampling error | `fractions.Fraction`, zero error |
| a "pass" means | the statistic did not exceed a simulated exact-uniform null band | `max_S |P(R_i = S) − 1/C(i,k)| == 0` exactly, at every prefix — a proof |
| cost | `2T` passes over the stream | 0 passes, 0 random bits |
| scale | any `n` | `C(n,k)` must be enumerable |

Three strengths of the baseline are implemented, not a strawman: the textbook
final-reservoir first-order test (the literal user ask), a strictly stronger pairwise
co-inclusion test on the same streams, and an **anytime** all-prefix version whose null
band is generated by the classical sampler itself.

## No external dataset, by construction

Uniformity of a reservoir sampler is a statement about *index* `k`-subsets, so the
canonical stream is the integer sequence `1..n`, generated in-script. The empty
`depends_on` is deliberate, not an omission. There are no LLM calls: OpenRouter spend is
**$0.00**. CPU only.

## The mathematics the code implements

**The accept coin is forced.** A `k`-subset `S'` of `[i]` that does not contain the
arriving item `i+1` can only survive by a rejection, so
`(1/C(i,k))(1 − p(S')) = 1/C(i+1,k)`, i.e. `p(S) = k/(i+1)` for *every* state. The system
is diagonal, hence of full column rank, hence its solution set is a single point. Every
valid sampler therefore pays at least `Σ_i h(k/i)` fair bits — that is the unavoidable
price of anytime uniformity. `forced.py` verifies this computationally rather than
asserting the algebra.

**Eviction is a transportation problem.** Accepted mass flows from each `k`-subset `S` of
`[i]` to one of its `k` children `T = S \ {x}`, and every `(k−1)`-subset must end with load
`(i−k+1)/k`. That is the biregular Johnson bipartite graph `J(i,k) → J(i,k−1)`.

**Why the minimum can be 0.** `Σ_S P(S) H(q_S)` is concave, so its minimum sits at a
*vertex* of the transportation polytope. Vertices are integral exactly when `k | (i−k+1)`,
equivalently `k | (i+1)`. There every source sends its whole mass to one child:
**the eviction entropy is exactly 0 and the rule is deterministic**.

**Why the other steps are cheap.** A vertex has forest support, so `#edges ≤ A + B − 1`
and `Σ_S H(q_S) ≤ B − 1`, giving at most `(C(i,k−1) − 1)/C(i,k) ≈ k/(i−k+1)` bits per
acceptance. All vertex coordinates lie in `(1/k)ℤ`, so a split source has a part in
`[1/k, 1−1/k]` and at least `⌈B/k⌉` sources must split, giving a matching lower bound.
Both bounds are **pre-registered**: every computed value is asserted to lie inside them and
a violation halts the run as a bug, not a discovery.

**The construction.** `r = ((Σ R − 1) mod k) + 1`; evict the `r`-th smallest held index.
Hand-check at `i=3, k=2`: `{1,2}→{2}`, `{1,3}→{1}`, `{2,3}→{3}` — a bijection onto the
singletons (gate G3).

## Candidates

| key | what it is |
|---|---|
| `S0` | **baseline**, classical Algorithm R: accept `k/i`, evict a uniformly random held item |
| `S1` | sum-mod-k eviction, minimally repaired by min-cost transportation flow |
| `S1n` | sum-mod-k, **no** repair — fully deterministic; the zero-randomness upper bound |
| `S1f` | flow-optimal: the integral certificate where `k \| (i+1)`, min-cost repair elsewhere |
| `S5-CIRC` | the blind-spot candidate: a genuine `O(k)`-memory circular-window sampler with *exact* first-order marginals and a broken joint law |
| `C-OFFBY1`, `C-OFFBY1b`, `C-FIFO`, `C-RR`, `C-SLOT0`, `C-NOACCEPT` | negative controls; each must light up |

`S5-CIRC` keeps an anchor `j` by a correct `k=1` reservoir and returns the circular window
`{((j−1+t) mod i) + 1 : t = 0..k−1}`. Each item lies in exactly `k` of the `i` windows, so
`P(x ∈ R_i) = k/i` exactly — while the support holds only `i` of the `C(i,k)` subsets.

```

verdicts.py       head-to-head: three MC tests vs the exact DP, on identical cells

method.py         gates -> screen -> held-out -> method_out.json
tests/            gates G1..G8
certificates/     integral fiber-map certificates, independently checkable
results/          full screen and held-out results
```

`pyproject.toml` pins every dependency, transitive ones included, to the exact version
installed in the `.venv` that produced `method_out.json`.

The exact DP and the transportation flow contain no randomness at all, so their outputs
are bit-identical by construction. Every Monte-Carlo block is seeded explicitly
(`PCG64`, with the per-candidate offset derived by `crc32` rather than Python's
per-process-randomised `hash`). The sha256 recorded in `screen_ranking.json` covers
everything except wall-clock timing, so a matching hash across two runs certifies both.

## Gates

| gate | what it guarantees |
|---|---|
| G1 | the baseline `S0` scores **exactly** 0 at every prefix — the instrument is valid |
| G2 | every negative control lights up, with its first failing prefix recorded |
| G3 | the hand-checked fiber map at `i=3, k=2` |
| G4 | the unrepaired deterministic rule's failure magnitude is reproducible |
| G5 | transportation arithmetic, both divisibility forms, and bracket containment |
| G6 | certificate round-trip — *and* a deliberately corrupted certificate is rejected |
| G7 | `S1`/`S1f` are exactly uniform end to end at every prefix |
| G8 | MC harness: skip-generation vs naive Bernoulli, null-band calibration, blind-spot |

## Deviations from the plan, and why

* **Null replicates raised from 10/20 to 200/100, and the decision rule changed to an
  exact Monte-Carlo p-value** `(1 + #{null ≥ observed})/(R+1) ≤ 0.01`. A `p95` estimated
  from 10–20 replicates is only the 1st–2nd order statistic; measured at `n=200, k=10,
  T=1e5` the true null `p95` is `3.59σ` while an 8-replicate band placed its `p99` at
  `3.03σ`, which flagged the provably-uniform baseline. Algorithm L was checked against an
  independent exact uniform-`k`-subset sampler first (Mann–Whitney `p=0.96`, KS `p=0.92`,
  pooled `χ²` at `T=1e6` `p=0.995`), so the miscalibration was in the band, not the sampler.
  The analytic Gumbel band is reported alongside as an independent cross-check.
* **The exact minimum eviction entropy is solved by MILP only where the instance is small
  enough**; elsewhere the output reports the pre-registered analytic bracket plus the
  constructive value achieved by the min-cost flow, and says per cell which it is. On
  divisible steps no search is needed at all: entropy is non-negative and the integral
  certificate achieves 0, so 0 *is* the exact minimum.
* **`S1`/`S1f` are absent from the large-`n` Monte-Carlo block.** Their eviction tables are
  indexed by `k`-subsets, so they exist only where `C(i,k)` is enumerable. They are run
  through the Monte-Carlo harness at the matched small-`n` cells instead, where both
  instruments see the same thing; no value is fabricated at `n=1000`.
* Quantities owned by the sibling instrument (floating-point Algorithm L, weighted
  A-Res/bottom-k, and *counted* DDG fair-coin flips) are marked
  `deferred_to_instrument_2` with a reason and no number. **Every bit figure here is
  analytic — an entropy — never a counted flip.**
